## About Me

I build software that has to stay correct under real constraints: money that cannot be double-spent, answers that must cite a source, and safety alerts that a family can trust.

Most of the work is Python and JavaScript, with a desktop ledger, a Flutter client, an Angular dashboard, and an ASP.NET live view alongside them. I would rather ship a small system with a clear invariant than a demo that only looks finished.

## Featured Projects

### [safestep](https://github.com/MortezaPZ/safestep)

A safety and tracking system for someone who wants to go out independently, and for the family that needs to know when something is wrong.

Node.js, Express, PostgreSQL, and a Flutter client. Live location, geofences, and fall detection sit in one product, with the person always able to see who is watching.

### [PersianLedger](https://github.com/MortezaPZ/PersianLedger)

A desktop multi-currency ledger. Each currency stays in double-entry books, dates are Jalali, and posted documents are not quietly rewritten.

Python, PySide6, SQLAlchemy, and SQLite, with an optional PostgreSQL server mode.

### [gemopt](https://github.com/MortezaPZ/gemopt)

A stone-cut optimizer. It varies cut parameters, traces light through each candidate, compares the result with a reference photo, and exports the chosen cut to 3ds Max.

Python, NumPy, and SciPy.

### [eitaa-forward-bot](https://github.com/MortezaPZ/eitaa-forward-bot)

Forwards posts from an Eitaa channel to as many as 70 groups, with a delay, rate limits, and a queue that survives a restart.

Python and SQLite. A failed send is retried. A duplicate post is not sent twice.

### [customer-churn-analytics](https://github.com/MortezaPZ/customer-churn-analytics)

Upload a customer CSV, train a churn model, and see who is likely to leave and which fields drove that score.

Django REST Framework, scikit-learn, and Angular. The holdout comparison is part of the repository, not a slide.

### [rag-document-assistant](https://github.com/MortezaPZ/rag-document-assistant)

Ask a question about your own documents and get an answer that points back to the passage it came from.

FastAPI, sentence-transformers, and SQLite. The default path runs locally and does not need an API key.

### [multi-agent-workflow-engine](https://github.com/MortezaPZ/multi-agent-workflow-engine)

A small workflow engine written directly, without a third-party agent framework. Independent steps run together, and a reviewer can send the draft back for a bounded number of revisions.

Python and FastAPI. The scripted backend runs with no API key.
